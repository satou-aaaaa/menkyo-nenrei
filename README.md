# 免許は何歳から？（menkyo-nenrei）

原付・普通二輪・普通・準中型・中型・大型・大型特殊・大型二輪・牽引・第二種などの運転免許を読んで、何歳からもらえるか（試験を受けられるか）を当てる1日5問の学習ゲーム。正解したら、ほかの免許が要るか（要らない・持っていることが要る・経験の年数も要る）も選ぶ。これから免許を取る人や、交通のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/menkyo-nenrei/>

- 中身は e-Gov 法令検索の道路交通法（<https://laws.e-gov.go.jp/law/335AC0000000105>）第84条（免許の種類）・第88条（免許を与えない年齢）・第96条（受験資格）に書いてあることだけです（2026-11-17 に読みました）。
- 説明は条文を、短く言いかえたものです。仮免許・試験の中身・教習所・費用・病気などの細かい決まり、政令で決める特例の細目は省いています。公式の情報の代わりではありません。実際に免許を取るときは、警察（運転免許センター）の案内で確かめてください。
- ほかの免許が要るかは、第96条の受験資格で分けています。
